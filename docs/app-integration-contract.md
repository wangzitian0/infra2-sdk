# App integration contract

This page states what an application does to run on the infra2 platform with infra2-sdk.
The tables at the end come from `data/shared_env.yaml` and `data/stages.yaml`; a test fails
when they are stale. Regenerate them with `python scripts/render_app_contract.py`.

## 1. Pin one SDK release

- Pin the release wheel URL with its sha256 in the lock file. Pin one exact version.
- infra2 accepts an app SDK version only inside its declared range and only after its
  Canary verified that version on staging (infra2 `common/deploy/canary_pin.py`).
- A major release removes names. Move to it in one change of the app.

## 2. Read the environment through the contract

- Use the canonical names of the table below. A retired name is not read; replace it with
  the name in the `Use` column. `check_shared_env_conformance(names)` lists every retired or
  deprecated name in a manifest. `python -m infra2_sdk.manifests --check` runs it on each
  manifest and exits 1 on a finding.
- Export the manifest of the settings class with
  `python -m infra2_sdk.runtime.config_schema module:Settings --json ... --check`.
- Call `assert_environment(manifest)` at start-up, so a missing required name stops the start.

## 3. Serve the standard endpoints and telemetry

- Call `init_service(app, service_name, ...)` once. It serves `/livez`, `/readyz`, `/health`,
  starts OpenTelemetry from the identity the deploy issues and adds `X-Request-ID`.
- Do not create OpenTelemetry providers or `structlog` configuration in the app.

## 4. Declare the deploy in `x-infra2` compose

- Write the stack as an `x-infra2` compose file. `compile_compose` adds the service defaults,
  one `vault-agent` sidecar (`x-vault`), Traefik routes (`x-routes`), capability environment
  blocks (`x-capabilities`) and, with `mode="preview"`, the preview database (`x-preview`).

## 5. Own your checks

- Declare a runtime hooks manifest of schema 3. List each check once with the cells where it
  runs. infra2 runs the platform cells; the app owns the cells of the table below.
- Each cell has a time budget. A check list that exceeds it fails.
- Run the pre-deploy enum check with `python -m infra2_sdk.runtime.schema_check` in the
  app image.
